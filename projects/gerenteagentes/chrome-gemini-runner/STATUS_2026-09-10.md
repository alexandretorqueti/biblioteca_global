### Fase 1: Validação Manual (Engenharia Reversa)

**Objetivo:** Capturar endpoints reais das IAs web via DevTools

**Passo a passo:**

1. **Acessar VNC:**
   ```
   http://192.168.1.8:6080/vnc.html
   Senha: global
   ```

2. **Abrir Chrome no VNC:**
   ```bash
   DISPLAY=:99 chromium --no-sandbox --user-data-dir=/tmp/webai-chrome-profile https://gemini.google.com/ &
   ```

3. **Capturar endpoints:**
   - Abrir DevTools (F12) → Network → Fetch/XHR
   - Fazer pergunta no Gemini
   - Copiar URL, Headers, Payload, Response
   - Salvar em `/tmp/webai-capture.txt`

4. **Repetir para GPT e Claude**

5. **Testar com curl:**
   ```bash
   curl -X POST "https://gemini.google.com/_/BardChatBackendData/..." \
     -H "Cookie: <cookies>" \
     --data-urlencode "at=<auth_token>" \
     --data-urlencode 'fz=[["olá"],["conv_id"],["resp_id"]]'
   ```

**Entregável:** Arquivo `webai-capture.txt` com endpoints validados

**Objetivo:** Substituir browser automation por chamadas HTTP diretas

**Arquivos a criar:**

1. **`src/providers/WebAIDirectProvider.ts`** (base)
   ```typescript
   abstract class WebAIDirectProvider {
     abstract authenticate(): Promise<void>;
     abstract sendMessage(message: string): Promise<string>;
     abstract parseResponse(data: any): string;
   }
   ```

   - Extrai cookies e auth token
   - Faz POST para endpoint do Gemini
   - Parse da resposta (formato wrb.fr)

   - Extrai access_token
   - Faz POST para backend-api/conversation
   - Parse da resposta SSE

## 🔧 Comandos Úteis

### Ver logs do database
```bash
curl http://localhost:3100/api/logs?limit=10 | jq
```

### Ver estatísticas
```bash
curl http://localhost:3100/api/stats | jq
```

### Limpar logs antigos
```bash
curl -X DELETE "http://localhost:3100/api/logs/cleanup?days=7"
```

### Testar API
```bash
curl -X POST http://localhost:3100/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini",

```
